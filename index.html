Longevity Intelligence Platform — 혈액 바이오마커 기반 생물학적 나이 예측 AI

GitHub →

  • 라이프스타일 슬라이더 → Causal DAG 전파 → Monte Carlo 500회로 생물학적 나이 변화 95% CI 실시간 계산
